## 분석 실행 계획

### Phase 1: 총괄 구조 파악 (계산식 파일 중심)

#### Step 1-1. "요약" 시트 분석
- **파일**: KDA 2기 평가_계산식 → `요약`
- **목적**: 전체 평가 항목, 배점, 가중치 총괄표 파악
- **확인**: 각 항목의 만점, 가중치(%), 평가 방식(가중평균 vs 순위배점)

#### Step 1-2. "종합" 시트 분석
- **파일**: KDA 2기 평가_계산식 → `종합`
- **목적**: 최종 점수 합산 수식 파악
- **확인**: 어떤 항목들이 합산되는지, 총점 계산 공식
- **수식 확인**: `get_sheet_formulas` 활용

### Phase 2: 항목별 점수 환산 방식 파악

#### Step 2-1. 출석률
- **시트**: 계산식 → `출석률`, `출석률-2`
- **확인**: 출석률(%) → 점수 환산 공식
- **평가 방식**: 가중평균? 순위배점?

#### Step 2-2. 출석 가산점
- **시트**: 계산식 → `출석률_가산점`
- **확인**: 출석 데이터 → 가산점 환산 기준

#### Step 2-3. 1차 프로젝트 결과
- **시트**: 계산식 → `1차 프로젝트 결과`, `1차 프로젝트 동팀 평가`
- **확인**: 강사평가 + 타팀평가 + 동료평가 → 종합 점수 수식
- **추가 원본**: 1차 프로젝트 폴더 내 팀별 평가지 `요약` 시트
- **핵심 질문**: 세 평가의 가중치 비율은? 순위배점이 적용되는 부분은?

#### Step 2-4. 2차 프로젝트 결과
- **시트**: 계산식 → `2차 프로젝트 결과`
- **확인**: 심사위원평가 + 타팀평가 + 동료평가 → 종합 점수 수식
- **추가 원본**: 2차 프로젝트 폴더 내 질문답변 사본, 동팀익명평가, 타팀평가
- **핵심 질문**: 세 평가의 가중치 비율은? 순위배점이 적용되는 부분은?

#### Step 2-5. 수업참여도
- **시트**: 계산식 → `수업참여도`, `강사평가최종`, `강사평가보정`
- **확인**: 강사 평가를 어떻게 수업참여도 점수로 환산하는지
- **추가 원본**: KDA 2기 강사님 평가표 → 과목별 시트

#### Step 2-6. 협업 및 태도
- **시트**: 계산식 → `협업 및 태도`
- **확인**: 강사 평가 + 운영진 태도평가 + 동료 태도 설문 → 환산 공식
- **추가 원본**: 운영진 평가 → `운영진 태도평가`, 추천인 조사 → `태도 요약`, `책임감 요약`

#### Step 2-7. 성장가능성
- **시트**: 계산식 → `성장가능성`
- **확인**: 성장가능성 점수 산출 수식
- **추가 원본**: 추천인 조사 → `성장성 요약`

#### Step 2-8. 동료추천
- **시트**: 계산식 → `동료추천`
- **확인**: 추천인 조사 → 동료추천 점수 환산
- **추가 원본**: 추천인 조사 → `동료추천 요약`

### Phase 3: 수식 검증 및 교차 확인

#### Step 3-1. 최종 결과 대조
- **파일**: KDA 2기 평가 vs KDA 2기 평가_계산식
- **목적**: 계산식 파일의 결과가 최종 평가 파일과 일치하는지 검증

#### Step 3-2. 평가 방식 분류 확정
각 항목에 대해 확정:
- [ ] 가중평균 방식인 항목 목록
- [ ] 순위 → 차등배점 방식인 항목 목록
- [ ] 각 방식의 구체적 파라미터 (가중치, 순위별 점수 등)

### Phase 4: 미확인 사항 질의
- Phase 1~3에서 수식만으로 파악 불가능한 부분을 사용자에게 질문

---

## 분석 순서 요약

```
Phase 1: 요약 → 종합 (전체 그림 파악)
    ↓
Phase 2: 항목별 시트 분석 (세부 수식 파악)
    ↓
Phase 3: 교차 검증
    ↓
Phase 4: 사용자 질의
```

## 핵심 확인 사항
1. 각 평가 항목의 **만점과 가중치**
2. **가중평균 vs 순위배점** 어떤 방식인지
3. 순위배점인 경우 **순위별 배점표**
4. 가중평균인 경우 **하위 항목별 가중치**
5. **복수강사추천 가산점**의 적용 방식 (boolean 1/0)
