# KDA 2기 점수 계산 체계 (최종)

## 1. 총괄 구조

### 총점 계산
```
총점 = 출석률 + 1차프로젝트 + 2차프로젝트 + 수업참여도 + 협업및태도 + 성장가능성 + 동료추천 + 출석가산점 + 복수강사추천
순위 = RANK(총점)
```

### 배점 총괄표
| # | 항목 | 만점 | 평가 방식 | 비고 |
|---|------|------|-----------|------|
| 1 | 출석률 | 20 | 공식 기반 (차감법) | 출석률% 입력 |
| 2 | 1차 프로젝트 | 15 | **순위 → 차등배점** | 팀순위(60) + 개인순위(40) → 15점 환산 |
| 3 | 2차 프로젝트 | 20 | 가중합 (팀내평가는 순위기반) | (키움+학생+팀내)/100×20 |
| 4 | 수업참여도 | 20 | 가중평균 | AVERAGE(과목별)×2 |
| 5 | 협업 및 태도 | 10 | 합산 | SUM(9항목)/10 |
| 6 | 성장가능성 | 10 | 가중평균 | AVERAGE(과목별) |
| 7 | 동료추천 | 5 | **사용자 입력** | 순위 기반 수동 배정 |
| 8 | 출석 가산점 | 2 | Boolean + 공과차감 | 완벽출석 2점, 공과시 차감 |
| 9 | 복수강사추천 | 1 | Boolean | 수동입력 1 or 0 |
| | **합계** | **103** | | 기본 100점 + 가산점 3점 |

### 순위 기반 차등배점 하한 원칙
5인팀과 6인팀 간 불평등 방지를 위해, **5인팀 최하위 점수 = 6인팀 최하위 점수** (하한).

| 차등배점 항목 | 만점 | 간격 | 하한 |
|--------------|------|------|------|
| 1차 팀 순위 | 60 | 5점 | 없음 |
| 1차 개인 순위 | 40 | 5점 | 20 |
| 2차 팀내 평가 | 30 | 5점 | 10 |

## 2. 항목별 상세 계산식

### 2-1. 출석률 (20점)

**입력**: 출석률 (%)

```
버림 = ROUNDDOWN(출석률)
차감점수 = MAX(0, 90 - 버림)
최종점수 = IFS(차감 > 10 → 0, 차감 <= 0 → 20, 그외 → 20 - 차감)
```

| 출석률(%) | 점수 |
|-----------|------|
| >= 90% | 20 (만점) |
| 80~89% | 20 - (90 - floor(출석률)) |
| < 80% | 0 |

---

### 2-2. 1차 프로젝트 (15점)

#### 팀 평가 (60점 만점) - 순위 차등배점

**팀 가중합** = (장원영×30 + 문혜영×15 + 이정수×15 + 학생평가×10) / 70

| 평가자 | 가중치 | 비고 |
|--------|--------|------|
| 장원영 강사 | 30 | |
| 문혜영 강사 | 15 | |
| 이정수 강사 | 15 | |
| 학생(타팀) 평가 | 10 | 각 팀별 평가지 요약 시트 |

**팀 순위 → 점수**: `60 - (순위-1) × 5` (하한 없음)

#### 개인 평가 (40점 만점) - 순위 차등배점

**개인 가중합** = (장원영×30 + 문혜영×15 + 이정수×15 + 타팀×10 + 동팀×30) / 100

| 평가 항목 | 가중치 | 비고 |
|-----------|--------|------|
| 장원영 강사 | 30 | |
| 문혜영 강사 | 15 | |
| 이정수 강사 | 15 | |
| 타팀 평가 | 10 | 팀별 평가지 요약 시트 |
| 동팀 평가 | 30 | 원본(0~10) × 4 스케일링 |

**팀내 순위 → 점수**: `max(20, 40 - (순위-1) × 5)` (하한 20)

#### 최종 점수
```
1차 프로젝트 = (개인평가종합 + 팀평가종합) × 15 / 100
```

---

### 2-3. 2차 프로젝트 (20점)

```
2차 프로젝트 = (키움평가 + 학생평가 + 팀내평가) / 100 × 20
```

| 항목 | 만점 | 수준 | 산출 방식 |
|------|------|------|-----------|
| 키움평가 | 60 | 팀 동일 | 심사위원 평가 (수동 입력) |
| 학생평가(타팀) | 10 | 팀 동일 | 타팀평가 응답 요약 |
| 팀내 평가 | 30 | **개인별** | 동팀 익명평가 → 순위 차등배점 |

#### 팀내 평가 내부 산출 (30점 만점)

1. 5개 항목 합산 (각 10점): 기여도, 의사소통, 기술습득, 문제해결 및 응대, 팀워크
2. 추천 횟수 → 추천랭크 → 추천점수: `max(2, 10 - (rank-1)×2)`
3. 총합 = 항목합(50) + 추천점수(~10) = ~60점
4. 총합 기준 팀내 순위
5. **순위 → 점수**: `max(10, 30 - (순위-1) × 5)` (하한 10)

---

### 2-4. 수업참여도 (20점)

**입력**: 6개 과목별 강사 평가 (각 10점 만점)

| 과목 | 강사 |
|------|------|
| 파이썬 | 김자영 |
| SQL | 김자영 |
| 금융데이터분석 | 김병철 |
| 데이터기반서비스구축(UX) | 심은숙 |
| 데이터기반서비스구축(AI) | 심은숙 |
| 보조강사 | 이정수 |

```
총점 = AVERAGE(과목별 점수) × 2
```
- AVERAGE는 빈 셀 자동 제외 (수강한 과목만)

---

### 2-5. 협업 및 태도 (10점)

**입력**: 강사 평가 6항목 + 팀원 평가 3항목

| 항목 | 만점 | 출처 |
|------|------|------|
| 김자영_파이썬 | 10 | 강사 평가 |
| 김자영_SQL | 10 | 강사 평가 |
| 김병철_금융데이터 | 10 | 강사 평가 |
| 심은숙_UX | 10 | 강사 평가 |
| 심은숙_AI | 10 | 강사 평가 |
| 이정수보조강사 | **20** | 강사 평가 |
| 팀원평가_성장 | 10 | 추천인조사 → 성장성요약 |
| 팀원평가_태도 | 10 | 추천인조사 → 태도요약 |
| 팀원평가_책임감 | 10 | 추천인조사 → 책임감요약 |

```
합계 = SUM(9개 항목)    // 최대 100점
총점 = 합계 / 10        // 최대 10점
```

**주의**: SUM 방식이므로 빈 셀은 0 처리됨

---

### 2-6. 성장가능성 (10점)

**입력**: 6개 과목별 강사 평가 (각 10점 만점) - 수업참여도와 동일 과목

```
총점 = AVERAGE(과목별 점수)
```
- AVERAGE는 빈 셀 자동 제외

---

### 2-7. 동료추천 (5점) - 사용자 입력

**입력**: "함께 일하고 싶다" + "추천하고 싶은 동기" 설문 언급 횟수

**산출**:
1. 두 항목 언급 횟수 합산
2. 합산 기준 순위 산정
3. **운영자가 순위를 보고 수동으로 점수 배정** (평가기준3)
   - 1위와 2위: 1점 차이
   - 3위와 4위: 하나의 구간
   - 기본 2점, 최대 5점

---

### 2-8. 출석 가산점 (2점)

**입력**: 결석, 지각, 조퇴, 외출, 지각공과, 결석공과 횟수

```
Step 1: 가산점여부 = IF(결석=0 AND 지각=0 AND 조퇴=0 AND 외출=0, 2, 0)
Step 2: 가산점여부가 2인 경우 공과 차감
  - 지각/조퇴/외출 공과: FLOOR(합계/3) × 0.1
  - 결석 공과: 개수 × 0.1
Step 3: 최종 = 가산점여부 - 공과차감
```

| 조건 | 점수 |
|------|------|
| 완벽 출석 (공과도 없음) | 2.0 |
| 완벽 출석 + 결석공과 1건 | 1.9 |
| 결석/지각/조퇴/외출 1건이라도 있음 | 0 |

---

### 2-9. 복수강사추천 (1점)

**입력**: 수동 (1 or 0)

---

## 3. 프로그램 입력 항목 정리

### 자동 계산 가능 항목 (원본 데이터 → 점수)
| 항목 | 필요 입력 |
|------|-----------|
| 출석률 | 출석률(%) |
| 1차 프로젝트 | 강사3명 점수, 타팀평가, 동팀평가, 팀 소속 |
| 2차 프로젝트 | 키움평가, 학생평가, 팀내 5항목+추천, 팀 소속 |
| 수업참여도 | 6개 과목별 점수 |
| 협업 및 태도 | 강사6항목 + 팀원3항목 |
| 성장가능성 | 6개 과목별 점수 |
| 출석 가산점 | 결석/지각/조퇴/외출/공과 횟수 |

### 사용자 수동 입력 항목
| 입력 코드 | 설명 | 사용처 |
|-----------|------|--------|
| 복수강사추천 | 1 or 0 (Boolean) | 복수강사추천 가산점 (1점) |
| 동료추천 점수 | 운영자가 순위 보고 수동 배정 (2~5점) | 동료추천 (5점) |

### 중도탈락자 처리
- 입력 대상 명단에서 **유지** (시스템 포맷 통일)
- **별도 표시** (예: 플래그 컬럼)
- 총점 계산에서 제외 또는 0 처리
